# AI Compass — 产品需求文档（PRD）

> 版本：v1.1 · 状态：MVP 已定稿 · 更新：2026-09-07

## 1. 产品概述

**AI Compass** 是一个「AI 产品导航站」：收集、整理、罗列市面上优质的 AI 产品，按分类清晰呈现，并支持一键跳转到产品官网，帮助开发者和工具使用者快速找到所需工具。

本项目是一个**纯静态站点**：数据本地维护、构建期生成静态页面，无后端、无 Python，仅实现「收集 + 跳转」。同时作为一次「工程化 vibe coding」练习，沉淀结构清晰、规范的工程实践。

## 2. 目标用户与痛点

| 目标用户 | 核心诉求 | 当前痛点 |
|---|---|---|
| 开发者 | 快速发现合适的 AI 工具 | AI 产品爆发式增长、信息分散，逐个调研成本高 |
| 独立开发者 / 创业者 | 寻找可集成的 AI 能力 | 缺少分类清晰、可信、可直接跳转的目录 |
| AI 工具使用者 | 对比、试用新产品 | 营销信息噪音大，难以快速定位 |

## 3. 核心价值

- **精选**：人工维护、去噪，只收录有价值的产品
- **分类清晰**：按场景 / 能力分类，检索高效
- **跳转顺畅**：一键直达官网，减少中间步骤
- **美观简洁**：现代化 UI，良好的浏览体验

## 4. 功能需求

### 4.1 MVP（P1，第一版必做）

- **F1 产品列表罗列**：以卡片网格展示产品，每张卡片包含名称、logo、分类、一句话简介、标签、定价、官网链接
- **F2 分类筛选**：按分类（大模型 / AI 编程 / AI 图像 / AI 视频 / AI 音频 / AI 办公 / Agent / 其他）过滤产品
- **F3 关键词搜索**：按名称 / 简介 / 标签进行关键词检索（纯客户端实现）
- **F4 详情与跳转**：点击产品查看详情卡片，并可跳转官网（新标签页打开）
- **F5 精选推荐**：首页优先展示 `featured` 精选产品

### 4.2 后续版本（P2，非 MVP）

- 用户提交产品（表单 + 审核，需引入后端）
- 收藏 / 点赞（需用户体系）
- 中英双语切换（i18n）
- 管理后台

## 5. 非功能需求

| 维度 | 要求 |
|---|---|
| 视觉 | 美观简洁，现代卡片式设计，深浅色适配 |
| 响应式 | 移动端优先，适配手机 / 平板 / 桌面 |
| 性能 | 纯静态生成，Lighthouse 性能 ≥ 90 |
| SEO | 每个产品可被搜索引擎收录（静态页 + meta） |
| 可访问性 | 语义化标签、键盘可操作、合理的对比度 |
| 可维护性 | 数据与展示分离，数据用结构化文件维护，改数据无需改代码 |

## 6. 验收标准（MVP Checklist）

- [ ] 首页能渲染产品卡片网格，卡片信息完整（名称 / logo / 分类 / 简介 / 标签 / 链接）
- [ ] 分类筛选可用，切换分类能正确过滤
- [ ] 搜索可用，能按名称 / 简介 / 标签命中（客户端实时过滤）
- [ ] 点击产品能跳转官网，新标签页打开
- [ ] 移动端布局正常，无横向滚动
- [ ] `data/products.json` 数据格式合法、字段完整
- [ ] 站点部署到 Vercel 并绑定自定义域名，可正常访问
